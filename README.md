# NamitDemoweb - Advanced Café/Restaurant Website

A modern, responsive website for **Namit's Café**, designed to showcase the menu, story, and services of a cozy café/restaurant. Built with **HTML, CSS, and JavaScript**, this project features a clean, aesthetic design with interactive elements.

---

## **Features**
✅ **Fully Responsive**: Works on mobile, tablet, and desktop.
✅ **Modern Design**: Warm, inviting aesthetic with a cozy café vibe.
✅ **Interactive Menu**: Organized by categories (Breakfast, Lunch, Desserts, Drinks).
✅ **Online Reservations**: Form to book a table with date, time, and guest count.
✅ **Contact Form**: For inquiries and feedback.
✅ **About Us Page**: Story, mission, vision, and team profiles.
✅ **Smooth Animations**: Hover effects, transitions, and mobile-friendly navigation.
